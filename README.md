# iPad Productivity App

This repo contains a cross-platform productivity app built with Flutter so it can run on iPad Mini 5 and Android tablets.

## Features
- Dashboard with summary cards
- Project tracking
- Task management with priorities and due dates
- Note taking
- Local persistence with SharedPreferences
- Responsive tablet layout

## Run locally
1. Install Flutter
2. Run `flutter pub get`
3. Start the app with `flutter run`

## Targets
- iPad Mini 5 / iPadOS
- Android tablets

## Tech stack
- Flutter
- Dart
- SharedPreferences
